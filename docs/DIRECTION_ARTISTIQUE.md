# Direction artistique

## Référence

Jeu de combat 2D dans l'esprit de *Guilty Gear Strive* : traits marqués, ombres fortes, typographie penchée, cartons de titre qui claquent. Le décor est une cour de temple à Tokyo, de nuit, sous la pluie.

## Palette

Les couleurs sont des jetons Tailwind déclarés dans `src/index.css`.

| Jeton | Valeur | Usage |
| --- | --- | --- |
| `ink` | `#08060d` | fond de page |
| `panel` | `#16121d` | panneaux |
| `line` | `#f4efe9` | texte principal |
| `muted` | `#b8afc4` | texte secondaire |
| `blood` | `#e8262d` | accent : boutons, soulignements, ombres de titre |
| `sakura` | `#ff8fc0` | focus clavier, touches florales |
| `violet` | `#8b6bff` | néons, adversaire |

Le rouge reste l'unique accent fort de l'interface. Le rose et le violet viennent du décor et servent en touches.

## Typographie

- **Anton**, en italique et en capitales, pour les titres et les boutons.
- **Barlow Semi Condensed** pour le texte courant et les étiquettes.

Les titres portent une ombre dure décalée (rouge puis noir), sans flou.

## Mouvement

- Les entrées sont franches : glissement avec inclinaison, flash blanc bref, trait rouge qui se trace.
- Le décor vit en continu mais reste au second plan : rien ne doit gêner la lecture du personnage.
- Tout effet clignotant ou brusque doit disparaître avec « Réduire les mouvements ».

## Le personnage

Peau brun foncé, locks noires, bandeau rouge à longs pans, veste noire à capuche doublée de rouge, t-shirt blanc, cargo noir, gants rouges, baskets noir, blanc et rouge.

## Personnages d'autres éditeurs

Ryu, M. Bison et les autres personnages de jeux existants sont protégés. Pour un site public, l'adversaire devrait être un personnage original.
